01 Static & Dynamic

Malware Analysis

Malware analysis is about understanding the enemy's weapons. I'm fascinated by how attackers craft malicious software — from simple droppers to sophisticated RATs and ransomware. Understanding how malware works from the inside is the best way to build defences against it.

I approach this from both the static side (reading disassembly, strings, imports) and the dynamic side (running samples in sandboxes, watching syscalls, network behaviour, registry changes).

02 PWN / CTF

Binary Exploitation

Binary exploitation is where security meets low-level engineering. I love the puzzle-like nature of finding and chaining together vulnerabilities — stack overflows, heap corruption, format strings, and ROP chains.

I practice primarily through CTF competitions and platforms like picoCTF and pwnable.kr. The process of turning a crash into a shell is one of the most satisfying experiences in offensive security.

03 IDA / Ghidra

Reverse Engineering

Reverse engineering is the art of reading what a machine says without having the source. I'm drawn to it because it demands patience, pattern recognition, and a deep understanding of how programs actually execute — not how developers say they do.

From crackmes to firmware analysis, RE is an essential skill that bridges malware analysis, vulnerability research, and binary exploitation.

04 Web / API

Bug Bounty

Bug bounty is where curiosity meets real-world impact. Unlike CTFs, bug bounty targets are production systems used by real people — which makes finding vulnerabilities both more challenging and more meaningful.

I focus primarily on web and API vulnerabilities — IDOR, authentication flaws, business logic bugs, and injection vulnerabilities. My work here has earned a Hall of Fame recognition and a rewarded disclosure.

05 LLM / Agentic

AI & LLM Security

Exploring the security implications of LLM-integrated and agentic AI applications. As AI systems gain autonomy — executing tools, managing memory, communicating with other agents — the attack surface expands in ways traditional AppSec hasn't fully addressed yet.

I've assessed real-world LLM applications for prompt injection, sensitive information disclosure, and excessive agency. I also use agentic AI daily as a productivity multiplier for recon, triage, and reporting.
